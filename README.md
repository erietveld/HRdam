## How to use the security prompt

Give `vibe-coding-security-prompt.md` to your AI coding tool (Claude Code, Cursor, Copilot, Lovable, Bolt, etc.) together with your project, then say:

> Follow the instructions in `vibe-coding-security-prompt.md` for this project.

It is a thinking aid, not a security audit.
